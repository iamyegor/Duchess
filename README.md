# Duchess - Gym Website 

[![React](https://img.shields.io/badge/React-61DAFB?logo=react&logoColor=black)](https://reactjs.org/)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)

A responsive frontend project for a gym chain, built with React and featuring an interactive Yandex Map integration. Demonstrates modern UI/UX implementation and component-based development.

## Key Features

*   **Interactive Yandex Map:** Displays multiple gym locations with custom map centering logic for optimal initial view.
*   **Responsive Design:** UI adapted for various screen sizes using Tailwind CSS.
*   **Informational Sections:** Includes designed areas for presenting membership plans and class schedules.
*   **Component-Based Architecture:** Built using reusable React components.

## Tech Stack

*   **Frontend:** React, React Router, Tailwind CSS
*   **APIs:** Yandex Maps API

## Conclusion

This project serves as a clear demonstration of frontend development capabilities using React. It highlights skills in building responsive user interfaces, integrating third-party mapping APIs with a focus on UX details.
